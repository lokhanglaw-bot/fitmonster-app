# Body Type Monster Images

## Monster Types (3 base types, each with 3 stages)
- **bodybuilder**: Orange/yellow creature with horns, round body, big eyes, white belly
- **physique**: Purple cat-like creature with pointed ears, big purple eyes, white belly
- **powerlifter**: Light blue blob creature with round head, dark eyes, pink cheeks, holding dumbbell

## Body Types to Generate (4 variants per monster type, stage 1 only for now)
- **skinny**: Thinner/slimmer version of the monster
- **lean**: Slightly athletic/toned version
- **fat**: Wider/rounder version with bigger belly
- **obese**: Very wide/round version, much larger belly

## Style
- Kawaii/chibi cartoon style
- White/transparent background
- 512x512 PNG
- Consistent with existing art style (big eyes, cute expressions, simple shapes)
